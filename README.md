# 学院学生信息库

学院学生信息库是一款在本机浏览器中运行的学生信息管理工具，支持信息看板、学生档案查询、表格导入、数据校验和备份恢复。

## 下载与启动

当前版本为 [v1.9.1](https://github.com/Lyy1029/student-directory/releases/tag/v1.9.1)。两个成品均已自带运行环境。

| 系统 | 成品下载 | 启动方法 |
| --- | --- | --- |
| macOS | [下载 ZIP](https://github.com/Lyy1029/student-directory/releases/download/v1.9.1/-v1.9.1-macos.zip) | 解压到本机可写入的文件夹，双击「学生信息库.app」。适用于 macOS 11 或更新版本，包含 Apple 芯片和 Intel 两种运行环境。 |
| Windows | [下载 EXE](https://github.com/Lyy1029/student-directory/releases/download/v1.9.1/-.-v1.9.1-windows.exe) | 将 EXE 保存到本机可写入的文件夹，双击运行。程序内含 32 位和 64 位组件。 |

启动后，系统会在本机浏览器打开信息看板。首次在新文件夹运行时，程序会在旁边创建空的 `学生信息.sqlite3`。macOS 版使用本地签名，若首次打开遇到系统验证提示，可参阅 [Apple 的说明](https://support.apple.com/zh-cn/102445)。

## 基本使用

1. **导入资料**。在侧栏点「导入学生信息」，选择 Excel（XLSX）或 CSV，核对导入预览后确认。
2. **查看档案**。在「学生查询」按姓名或学号查找。也可以在信息看板按年级或专业筛选，从图表查看名单和档案。
3. **备份与迁移**。在「备份与恢复」点「下载当前数据库」。换电脑时，在新设备启动程序，通过同一入口选择备份，核对预览后确认恢复。

发布包只包含程序和运行组件，试用请使用虚构资料。真实学生档案、表格和备份请保存在本机或经授权的受保护存储位置。

Mac 版已在 Apple 芯片机型上用空库和模拟档案验证。Windows 成品已核验封装内容，实机运行待验证。
